## 🚀 Sobre mim

Olá! Me chamo **Henrique Parreira Gonçalves**, tenho 21 anos e sou de Formiga, Minas Gerais.

Sou estudante do 8º período de Ciência da Computação no Centro Universitário de Formiga (UNIFOR-MG) e desenvolvedor com foco em Backend, especialmente no ecossistema Java e Spring Boot.

Atualmente, trabalho com desenvolvimento e manutenção de sistemas, implementação de funcionalidades, integração entre serviços e desenvolvimento de APIs REST. Tenho contato com sistemas corporativos, bancos de dados relacionais e ferramentas utilizadas no desenvolvimento de aplicações.

Minha experiência envolve tecnologias como Java, Spring Boot, Spring Data JPA, Hibernate, PostgreSQL, Oracle, Redis e Keycloak, além de ferramentas como Git, Docker e Postman.

Estou sempre buscando aprimorar minhas habilidades, aprofundar meus conhecimentos em arquitetura de software e desenvolver soluções cada vez mais organizadas, eficientes e de fácil manutenção.

🎯 **Objetivo:** evoluir continuamente como desenvolvedor backend e me especializar no ecossistema Java, contribuindo para o desenvolvimento de sistemas robustos e escaláveis.
